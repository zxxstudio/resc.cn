## 起因

QQ 宠物已经停服好几年了，但那个小企鹅在桌面晃来晃去的记忆还在。最近在折腾网站，突然想：能不能给 resc.cn 也加一个类似的宠物？

想法很简单：
- 一个 3D 角色悬浮在网站右下角
- 会动、会互动、能聊天
- 形象要酷一点，符合"小性工作室"的调性

## 找工具：图片转 3D

先搜了一圈，发现微软开源的 **TRELLIS-2** 最合适：
- 免费开源（MIT 协议）
- 4B 参数，质量高
- 支持 GLB 导出（网页友好）
- 在线就能用：[trellis-2.com](https://trellis-2.com/)

找了一张酷酷的卡通图——黑色短发、墨镜、高领毛衣——上传后等了 2 分钟，生成了一个 26MB 的 GLB 模型。

效果：⭐⭐⭐⭐
- 整体结构对
- 纹理清晰
- 墨镜、衣服细节都在
- 唯一缺点是文件有点大（后面可以压缩）

## 集成到网站

### 1. 技术栈

网站是 VitePress + Vue 3，用 Three.js 加载模型。

```bash
pnpm add three
```

### 2. 组件实现

创建 `Pet3D.vue` 组件：

```vue
<template>
  <div class="pet3d-container">
    <canvas ref="petCanvas" />
    <div v-if="bubbleText" class="pet3d-bubble">{{ bubbleText }}</div>
  </div>
</template>

<script setup>
import * as THREE from 'three'
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js'

// 加载模型
const loader = new GLTFLoader()
loader.load('/models/pet.glb', (gltf) => {
  scene.add(gltf.scene)
})

// 动画循环
function animate() {
  // 轻微浮动
  petModel.position.y = Math.sin(t * 1.5) * 0.05
  // 看向鼠标
  petModel.rotation.y += (targetRotY - petModel.rotation.y) * 0.05
  renderer.render(scene, camera)
  requestAnimationFrame(animate)
}
</script>
```

### 3. 互动设计

- **鼠标跟随**：宠物会慢慢转向鼠标位置
- **点击反馈**：点击后快速转圈 + 弹出对话气泡
- **对话内容**：
  - "嗨，我是站长的 3D 宠物 😎"
  - "点我干嘛？"
  - "别戳了，墨镜要掉了"
  - "今天也要酷酷的"
  - ...

### 4. 性能优化

- **桌面端才加载**：手机端隐藏（省流量，26MB 模型太大）
- **懒加载**：用户可以点关闭，状态存 localStorage
- **像素比限制**：`Math.min(window.devicePixelRatio, 2)` 避免 4K 屏太卡

## 遗憾与下一步

### 遗憾

- **模型文件太大**（26MB），加载要几秒钟
- **还没接入真正的 AI**，现在只会说预设的话

### 可以继续做的

1. **模型压缩**：用 Draco 压缩到 5-8MB
2. **AI 对话**：接入聊天 API，宠物能真的聊天
3. **更多互动**：
   - 喂食系统
   - 心情状态（开心/生气/睡觉）
   - 成长系统（会升级、换装）
4. **换模型**：如果不喜欢现在的形象，可以随时用 TRELLIS-2 生成新的

## 总结

从"想做一个宠物"到"上线看到效果"，大概花了 2 小时：
- 30 分钟：找工具、生成 3D 模型
- 1 小时：写组件、调试互动
- 30 分钟：部署上线

现在的宠物还很简单，但已经能动了、能互动了。后面慢慢加功能，让它越来越"活"。

**核心思路**：先做出最小可用版本，再迭代优化。
