🎬 封面设置

🔗 友链名单 分组与条目可增删

「友情链接」页面展示的名单。分组就是「推荐 / 小伙伴们」这样的分类，条目是里面的每个站点（头像、名称、简介、网址）。

👥 友链圈子

两项都是可选的锦上添花功能，暂时用不上可以留空。

📊 站点统计 & 图片灯箱

灯箱默认用的是公益 CDN 镜像，能正常加载就不用改。

⇥ 外链跳转提示

开启后，站里指向别的网站的链接会先跳到一个「即将离开本站」的提示页，再跳过去。

📋 页脚站点地图

页脚底部的链接分组（如：博客 / 页面）。

📄 头部注入（inject.header）

插入到 <head> 的资源引用，如 favicon / RSS / 字体等。格式：标签 + 属性 JSON。

↓ 更多导航（navMore）下拉菜单

鼠标悬停「更多」按钮时显示的下拉内容，分组展示，每组有 name 和 list（子项）。子项格式：名称 / URL / SVG 图标代码。

📄 高级 JSON（兜底编辑）

当表单无法满足需求时，可直接编辑这里完整的 JSON。保存时以这里的 JSON 为准（即使和表单不一致）。

改动「导航、导航菜单、友链名单、统计、灯箱、外链跳转、封面」这类需要打包的配置时，保存后点一下「重新构建并上线」，等提示出现再刷新前台。其余（站点信息、关于我、项目、打赏、页眉等）保存后直接刷新就生效。
